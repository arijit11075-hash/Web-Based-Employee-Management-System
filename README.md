Project Overview: Employee Management System

A modern, responsive web application built with HTML, CSS, and JavaScript designed to manage company employees, roles, and administrative workflows efficiently. 

Core Modules & Progress:
- Authentication & Login: Clean corporate login interface with role selection for Managers and Employees.
- Manager Dashboard: Split-screen interface featuring a sidebar menu, analytics stats cards, and an employee management table with interactive actions.
- Tech Stack: Pure HTML5, CSS3 (Flexbox, standard color palette), and vanilla JavaScript.
- Version Control: Managed via Git and hosted on GitHub.
