# Employee Management System 🚀

A modern, responsive web application designed to manage employees and administrative workflows efficiently, featuring role-based access for Managers and Employees.

## 🌟 Features (Day 1 Progress)
- **Professional Login Interface**: Clean and modern corporate UI with a dark navy gradient background and a 3D glassmorphic card layout.
- **Role-Based Selection**: Dedicated login options for **Managers** and **Employees**.
- **Interactive UI Elements**: Smooth transition effects, custom focus glows, and input field states.
- **Security & Usability**: Disabled pinch-zoom/trackpad zooming to lock the layout into a clean, application-like experience.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3 (Advanced Flexbox, Gradients, Custom Shadows)
- **Scripting**: JavaScript (Upcoming logic & LocalStorage integration)
- **Design Standard**: Modern dashboard aesthetics tailored for enterprise applications.
